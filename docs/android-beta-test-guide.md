# CamTransfer Android 内测说明

版本：0.1.0-beta.1

这是个人开发者内测版本，不是 FUJIFILM / 富士胶片官方应用。内测包有效期为 60 天。

## 安装前

- 需要 Android 手机。
- 需要允许安装 APK。
- App 不需要服务器，不会上传照片、视频或相机内容。
- 首次打开会请求蓝牙、定位、照片/视频相关权限；这些权限用于发现相机、连接相机 Wi-Fi、保存照片。

## Wi-Fi 传图

1. 打开相机蓝牙，进入配对或连接状态。
2. 在 App 首页点 `连接相机`。
3. 按相机屏幕提示确认连接。
4. 配对成功后点 `进入相机相册`。
5. 在照片筛选页选择照片并点 `下载`。

传输过程中手机会连接相机 Wi-Fi。相机 Wi-Fi 通常不能上网，这是正常现象。

## 有线导入 Beta

1. 用 OTG/数据线连接手机和相机。
2. 相机上选择 `USB`、`PC连接`、`读卡器` 或 `照片传输` 之类模式。
3. 在 App 首页点 `有线导入 Beta`。
4. 如果 Android 弹出 USB 权限，请选择允许。

有线导入依赖相机是否被 Android 识别为 MTP/PTP 文件设备。不同相机、手机、线材兼容性可能不同；如果无法进入照片页，请导出诊断日志反馈。

## 出问题怎么反馈

请在 App 首页点 `导出诊断日志`，把导出的文本文件发给开发者，并同时说明：

- 手机型号：
- Android 版本：
- 相机型号：
- 使用方式：Wi-Fi / 有线
- 问题发生步骤：
- 是否能稳定复现：

诊断日志只保留最近 1 小时内容，并会脱敏文件名、相机名、Wi-Fi、路径、设备标识等信息。若 App 闪退，重新打开后也可以导出诊断日志。

## 已知限制

- 有线导入目前是 Beta。
- HEIF/RAW 的显示和缩略图取决于 Android 系统、相机返回数据以及设备解码能力。
- 内测包过期后无法继续使用，需要联系开发者获取新版本。
- 请不要把内测包公开上传到网盘、论坛、应用市场或第三方分发平台。
