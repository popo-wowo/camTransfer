核心说明

核心相机连接与传图功能通过 USB、蓝牙或局域网运行。照片和连接记录主要在你的设备上处理，App 不会自动将照片或诊断日志上传给开发者。购买和恢复购买通过 Apple 服务进行；你主动开启局域网选片、导出分享或发送客服邮件时，相关信息会按你的操作提供给接收方。

一、我们处理哪些信息

1. 相机连接与配对信息

为发现、识别、配对和重新连接相机，App 在本机处理相机名称、型号、序列号、蓝牙设备标识、配对状态、连接时间，以及相机 Wi-Fi 的网络名称（SSID）、连接凭据和局域网地址。需要记住的相机信息保存在 App 本地存储中；连接凭据用于连接对应相机，不用于连接开发者服务器或广告追踪。

2. 照片、视频及文件信息

当你浏览、预览、下载、导出或删除文件时，App 处理相机或已授权系统相册中的媒体、缩略图，以及文件名、格式、大小、拍摄日期、方向等元数据。原始文件可能自带拍摄地点等 EXIF 信息，传输或分享原文件时这些信息可能一并保留。App 不会为了传图而请求获取手机的实时定位。

缩略图、预览缓存、下载队列、下载历史、选片标记和操作偏好在本机保存，用于显示状态、减少重复读取及恢复任务。保存到系统相册的文件由 iOS 照片服务管理。

3. 试用与购买信息

App 在本机保存有线和无线功能的试用开始日期，以及已验证的购买权益。购买、恢复购买和退款状态通过 Apple StoreKit 处理；App 接收商品标识、交易验证结果、有效权益及适用的到期或撤销状态，以判断可用功能。开发者不会通过 App 获取你的银行卡号、支付密码或 Apple 账户密码。

4. 本地诊断日志

为排查连接和下载故障，App 在本机记录操作时间、连接状态、错误信息、相机标识、网络连接信息及相关文件信息。日志采用容量限制和轮换机制，较旧记录可能被覆盖。通过“诊断日志”导出时，还会包含 App 版本、设备类型和系统版本。App 不会自动将这些日志发送给开发者。

你可以主动复制或导出日志，并自行选择接收方。导出时会对部分密码字段做遮盖，但这不意味着所有可识别信息都已移除；发送前请检查内容，不要提供不必要的照片、凭据或其他私人信息。

5. 客服沟通

如果你主动联系开发者，我们会收到你使用的邮箱地址、邮件内容及你选择附带的照片、截图或诊断文件，仅用于处理咨询、故障和隐私请求。请只发送解决问题所需的信息。

二、系统权限及其用途

  • 蓝牙：发现、配对及连接支持的相机，并在系统允许时维持必要的相机连接。
  • 本地网络：连接相机 Wi-Fi，读取和传输文件，以及在你开启现场选片时与同一局域网的设备通信。
  • 添加照片：把你下载或导出的照片、视频保存到系统相册。
  • 读取照片：显示系统相册中的媒体，以及确认已下载内容。支持有限照片访问时，以你选择的授权范围为准。

你可以在 iOS“设置”中查看和更改授权。拒绝或撤回权限会影响依赖该权限的功能；其他不依赖该权限的功能仍可使用。App 当前不申请通讯录、麦克风或手机实时定位权限。

三、共享、局域网选片及第三方服务

我们不出售你的个人信息，不使用照片进行广告定向，也未在 App 中集成广告追踪或第三方用户行为统计服务。除你主动发起的操作、提供功能所需的系统服务或依法必须履行的义务外，我们不会将信息提供给其他方。

  • 现场选片：你主动开启后，App 在本机启动局域网网页服务，向可访问该服务的设备提供当前相册列表的文件名、格式、文件大小、缩略预览及选片标记。收到链接或二维码且处于可达网络的其他人可能查看这些内容。该服务使用局域网 HTTP，不能视为加密的互联网私密相册；请仅在可信网络使用，按需关闭选片会话。关闭会话无法撤回他人已保存或截图的内容。
  • 系统分享与剪贴板：只有在你选择分享或复制时，内容才会交给你选择的 App、设备或系统剪贴板。接收方及其服务适用各自的隐私规则。
  • Apple：App Store、内购、系统照片和系统备份等服务由 Apple 提供。如果你开启 iCloud 照片或设备备份，相关数据可能由系统按你的设置同步；这不是 CamTransfer 向开发者上传照片。参见 Apple 隐私政策。
  • 客服邮件：邮件由你的邮件服务商与开发者使用的 QQ 邮箱传递、保存。腾讯相关规则参见 腾讯隐私保护平台。发送邮件前，请自行确认附件内容。

四、保存地点、期限与删除

App 的相机配对记录、试用记录、购买权益缓存、媒体缓存、任务及诊断日志主要保存在你的设备中。配对信息和偏好在对应功能需要期间保留；缓存可能被 App 或系统清理；日志随容量轮换；购买记录由 Apple 按其规则保留。我们没有用于自动接收 App 照片或连接日志的自营云端账户系统。

  • 删除已配对相机可移除对应的 App 配对记录；系统蓝牙配对和 Wi-Fi 设置需在 iOS 设置中另行管理。
  • 在 iOS“设置 → 通用 → iPhone 储存空间 → CamTransfer → 删除 App”中可删除本机 App 及相关数据。“卸载 App”会保留文稿与数据，不能等同于删除数据。系统备份中的副本需按 Apple 提供的方式管理。
  • 已保存到系统相册或导出到其他位置的文件不会因删除 App 自动删除，应在相册或对应位置另行删除。
  • 你主动发给客服的邮件和附件，仅在解决问题、处理你的请求及履行法定义务所需的期间保存；不再需要时删除，或根据你的有效请求依法处理。

开发者不会通过 App 自动将本机照片或诊断日志传到境外服务器。你主动使用 Apple 云服务、第三方分享、客服邮件或本支持网站时，相关提供商可能按其政策在不同地区处理信息；这不属于纯本地处理，请同时查看对应服务政策。

五、你的选择与个人信息权利

你可以管理系统权限、删除配对记录、关闭选片会话，并决定是否分享内容和日志。App 无需注册开发者提供的账户，因此不存在需要注销的 CamTransfer 云端账户。

对于开发者实际持有的信息（例如你主动发送的客服邮件），你可以通过下方邮箱申请查询、复制、更正、删除、撤回相关同意或解释信息处理规则。我们会在必要范围内核实身份，并依法及时答复；不会为身份核实索取与请求无关的信息。我们无法远程读取或删除仅保存在你设备中的文件，但可以提供操作帮助。

六、信息安全与未成年人

我们遵循最小必要原则，尽量采用本地处理、系统权限控制及日志容量限制，减少不必要的信息流转。任何存储和通信方式都不能保证绝对安全。请保护手机、相机及局域网访问权限，分享前检查敏感内容。

CamTransfer 并非专为不满十四周岁的儿童设计。未成年人应在监护人指导下使用；如需处理儿童个人信息，应取得监护人同意。监护人发现儿童向我们提供了信息，可联系开发者申请处理。

七、本支持网站

本支持网站使用 GitHub Pages 托管。页面不包含我们添加的统计脚本、广告、外部字体、注册表单或追踪 Cookie。访问网站时，GitHub 会为安全及提供网页服务记录访问者 IP 地址等必要信息，具体处理与保留规则由 GitHub 说明。网站访问不包含上传 App 内照片或连接日志。参见 GitHub Pages 说明和 GitHub 隐私声明。

八、政策更新

功能或信息处理方式发生变化时，我们会更新本政策并注明日期。对你的权利有重大影响的变化，将通过 App 内说明等适当方式提醒；依法需要重新取得同意的，会在相关处理开始前取得同意。
